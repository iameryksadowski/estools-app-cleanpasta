Cleanpasta 1.1.1

Paste formatted text without backgrounds, colors and fonts. Bold, lists, links and line breaks stay.

Shortcuts

Click a field and press the keys. Delete or Backspace clears it. The tray menu always works. If a shortcut is taken, choose another one.

Formatting

General

No administrator password. Open a new terminal after installing.

Updates

Updates require Eryk's public signing key.



Windows permissions
Paste Clean presses Ctrl+V after you release the shortcut keys. Windows may block pasting into apps running as administrator. In that case use Ctrl+V yourself.
